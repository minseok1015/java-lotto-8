# java-racingcar-precourse

## 1. 프로젝트 개요
### 1.1 프로젝 이름
로또

### 1.2 프로젝트 설명
간단한 로또 발매기를 구현한다.




---
## 2. 구현 기능

### 2.1 로또 구입 금액을 입력 받는다.

### 2.2 발행한 로또 수량 및 번호를 출력한다.

### 2.3 당첨 번호를 입력 받는다.

-  2.3.1 예외 상황 시 에러 문구를 출력하는지 확인

### 2.4 보너스 번호를 입력 받는다.

### 2.5 당첨 내역을 출력한다.

- 2.5.1 당첨 내역의 총 갯수가 로또 구입 갯수랑 맞는지 확인
- 2.5.2 수익률은 소수점 둘째 자리에서 반올림한다. 
  - 수익률 소수점 둘째 자리에서 반올림 되는지 확인 
  - 수익률이 나눠 떨어질 경우에도 소수점 첫째짜리까지 표시하는지 확인(예시 : 100.0%)



## 3. 예외 처리

### 3.1 로또 구입 금액 입력 시 예외
- 3.1.1 로또 구입 금액이 1000원 단위로 나눠 떨어지지 않는 경우
- 3.1.2 로또 구입 금액이 음수일 경우
- 3.1.3 로또 구입 금액이 숫자가 아닐 경우

### 3.2 당첨 번호 입력 시 예외
- 3.2.1 당첨 번호가 1~45 사이의 숫자가 아닐 경우
- 3.2.2 중복된 당첨 번호를 입력 시
- 3.2.3 당첨 번호가 문자일 경우
- 3.2.4 6개를 입력하지 않았을 경우

### 3.3 보너스 번호를 입력 받을 때 예외
- 3.3.1 보너스 번호가 기존 번호 6개 중 하나랑 겹칠 경우
- 3.3.2 보너스 번호가 1~45 사이의 숫자가 아닐 경우
- 3.3.3 보너스 번호가 문자일 경우
- 3.3.4 보너스 번호를 1개 입력하지 않은 경우

### 3.4 로또번호를 랜덤으로 만들때 예외
- 3.4.1 로또번호가 없는 경우
- 3.4.2 로또번호가 6개가 아닌 경우
- 3.4.3 로또번호가 중복된 경우
- 3.4.4 로또번호가 1~45사이가 아닐 경우
